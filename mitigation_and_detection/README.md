# Mitigation and Detection of Timer-free methods

This folder is structured as follows:
- `spectre_mitigation`: Two mitigation against the Spectre attack that also apply timer-free methods;
- `hpc_evaluation`: Collection of HPC values during the execution of the differents attackss and benign application in order to compare the results with state of the art and determine whether  the existing HPC detection mecanism also works for timer-free methods.
